# Weather Data Analysis and Prediction

A beginner-friendly Python project that analyzes weather data and uses Machine Learning to predict temperature.

## Features

- Loads weather data from a CSV file
- Calculates average temperature, humidity, rainfall and wind speed
- Displays a temperature trend graph
- Displays a humidity vs rainfall graph
- Uses Linear Regression for temperature prediction
- Accepts new weather values from the user
- Predicts temperature based on humidity, rainfall and wind speed

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## How to Run

1. Open this folder in Visual Studio Code.
2. Open the VS Code terminal.
3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the program:

```bash
python weather_prediction.py
```

5. Enter humidity, rainfall and wind speed when asked.

## Dataset

The `weather_data.csv` file contains sample weather observations for 60 days.

## Project Objective

The objective of this project is to demonstrate basic data analysis, data visualization and machine-learning prediction using Python.
